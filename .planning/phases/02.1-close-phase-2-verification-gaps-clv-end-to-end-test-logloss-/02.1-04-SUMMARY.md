### `src/bip/train/metadata.py` (modified)

Three new fields inserted between `git_commit` (line 44) and `to_dict` method:

```python
# --- NEW in Phase 02.1 (D-13) ---
# Nullable defaults preserve Phase 2 test compatibility (research finding 5; Pitfall 7).
# logloss_improvement_pct: POSITIVE = calibration improved loss (Pitfall 6).
```

## Key Decisions

- **`float | None = None` over `Optional[float] = None`:** matches existing `git_commit: str | None = None` style at metadata.py:44 (PEP 604 syntax, project Python 3.12).
- **No positive-only validator on `logloss_improvement_pct`:** Pitfall 6 — calibration regressions are real and must round-trip cleanly so D-16 can flag them as failed gates downstream.
- **Wave 0 stub replaced rather than created new:** the 02.1-00 stub used module-level `pytest.mark.skip` so the file existed but was inert; this plan removes the gate and writes real assertions.
- **`to_dict()` body untouched:** Pydantic's `model_dump()` automatically includes new fields; no manual mapping needed.
