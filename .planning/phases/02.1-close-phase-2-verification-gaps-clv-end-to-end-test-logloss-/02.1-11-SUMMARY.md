## Decisions Made

- **Wiring-only assertions, not value assertions.** Synthetic data with random labels and random odds produces uncorrelated probabilities; any `assert clv_pct > 0` would be flaky. The gate's job is to catch wiring regressions (field renames, dropped writes, type changes), not validate model performance — that's plan 02.1-12's smoke train.
- **Hour-spaced computed_at instead of plan-literal single timestamp.** The plan's pseudo-code used `["2024-08-01T00:00:00+00:00"] * n` for every row. This trips `WalkForwardSplitter`'s strict-< temporal-leakage assertion (`dates[train_idx].max() < dates[test_idx].min()` becomes `T == T`, not `<`). Fixed by spacing rows by 1 hour each — preserves total ordering and satisfies the assertion.
- **Expect 5 folds, not 3.** Pipeline hardcodes `WalkForwardSplitter(n_splits=5)`; the plan's "n_splits=3" wording was aspirational (no constructor kwarg accepts it). Assertion changed to match implementation reality.
- **logloss_calibrated only on the last fold.** Pipeline back-fills calibration only on `fold_details[-1]`; folds 0..n-2 keep `logloss_calibrated=None`. Assertion checks the index-conditional pattern instead of asserting all folds have calibrated values.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] Synthetic features had a single computed_at, breaking WalkForwardSplitter's leakage assertion**
- **Found during:** First test run RED phase
- **Issue:** Plan's `synthetic_e2e_data` recipe used `["2024-08-01T00:00:00+00:00"] * n`. `WalkForwardSplitter` enforces `dates[train_idx].max() < dates[test_idx].min()`; with all rows sharing one timestamp the assertion fires on every fold.
- **Fix:** `computed_at = [(base_dt + timedelta(hours=i)).isoformat() for i in range(n)]` — unique per row, monotonic increasing, satisfies the assertion.
- **Files modified:** tests/test_training_pipeline_e2e.py
- **Verification:** Pipeline ran 5 folds without leakage assertion firing.
- **Committed in:** 012fb31

**2. [Rule 1 — Bug] df_results join leaked partition columns into the feature matrix**
- **Found during:** Pipeline raised `ValueError: could not convert string to float: 'test_league'` inside XGBoost during fold 0
- **Issue:** Plan 02.1-10 wrote `df.join(df_results.filter(pl.col("status") == "finished"), ...)` — no `.select()` projection, so `sport`, `league`, `season` columns existed in BOTH frames and Polars created `sport_right`, `league_right`, `season_right` collision columns. The pipeline's `drop_cols` set didn't include `_right` variants, so they survived into `feature_cols` and ended up in `X` as object-dtype strings, crashing XGBoost on `_ensure_np_dtype`.
- **Fix:** `df.join(df_results.filter(...).select(["fixture_id","home_goals","away_goals","status"]), on="fixture_id", how="inner")` — only fixture_id + the actual results data, no partition columns to collide.
- **Files modified:** src/bip/train/pipeline.py
- **Verification:** Pipeline ran all 5 folds successfully; no string columns leaked into X.
- **Committed in:** 012fb31

**3. [Rule 1 — Bug] _EnsembleProbaWrapper incompatible with sklearn 1.8 + joblib**
- **Found during:** Calibration step crashed first with `InvalidParameterError: ... must be an object implementing 'fit' and 'predict'`, then with `__sklearn_tags__` AttributeError, then with `PicklingError` on `joblib.dump`.
- **Issue:** Plan 02.1-10's `_EnsembleProbaWrapper` was (a) defined inside `run()` (local class — joblib can't serialize), (b) had no `predict()` method (sklearn 1.8 `cross_val_predict` validation requires it), and (c) inherited from nothing, so `__sklearn_tags__` was missing — sklearn 1.8 validates this on every wrapped estimator.
- **Fix:** Class hoisted to module scope; inheritance changed to `(ClassifierMixin, BaseEstimator)` (MRO order matters — BaseEstimator on the right per sklearn deprecation guidance); `_estimator_type = "classifier"` declared; `predict()` added (`self.classes_[np.argmax(self.predict_proba(X_in), axis=1)]`).
- **Files modified:** src/bip/train/pipeline.py (also added `from sklearn.base import BaseEstimator, ClassifierMixin` import)
- **Verification:** All 120 tests pass; calibrator artifact written to `models/football/test_league/v1/calibrator.joblib` without serialization errors.
- **Committed in:** 012fb31
