## Decisions Made

- **walk_forward_mean_clv_pct made nullable.** D-11 requires the field to be None when no fold reaches >=20 picks; the existing `float`-only type would have caused a Pydantic validation crash on legitimate small-sample runs. All existing tests pass numeric values, so backward-compat is preserved.
- **Sort opening_matrix and closing_matrix by the same date-order permutation as X/y/dates.** Failing to do so would misalign test_idx with the odds rows after the date-sort step, silently corrupting CLV.
- **Drop status, opening_home, opening_draw, opening_away from feature columns.** Without explicit exclusion, the join would inject these as features and pollute the model.
- **Closing proxy = opening for now (D-02).** Plan 02.1-07 stubbed `fetch_historical_closing` because /v4/historical implementation is deferred. Until then, CLV vs the same-source opening odds is a 0% baseline plus slippage; this is the documented Phase 02.1 limitation.
