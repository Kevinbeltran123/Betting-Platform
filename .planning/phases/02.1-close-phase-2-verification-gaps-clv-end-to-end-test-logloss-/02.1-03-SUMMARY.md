## Decisions Made

- **Function signature** — `simulate_pick(model_probs: np.ndarray, opening_odds: np.ndarray, threshold: float = EDGE_THRESHOLD_PCT)`. Default-binding the threshold kwarg at definition time (rather than at call time) is intentional: the Phase 3 pick engine should import EDGE_THRESHOLD_PCT explicitly when it wants the project default, making the dependency visible. Tests override via `threshold=0.01` kwarg.
- **NaN sentinel for missing odds** — Returning None (not raising) on NaN odds matches the upstream design: plan 02.1-10's CLV loop iterates `for i in range(len(test_idx)): pick = simulate_pick(...); if pick is None: null_this_fold += 1; continue`. Raising would force every caller into try/except for an *expected* condition.
- **No floor at 0 for max edge** — `if float(np.max(edge)) < threshold: return None` rejects negative-edge picks in the same predicate as below-positive-threshold picks. No need for `max(0, ...)` clamp; `< threshold` already covers it (threshold defaults positive, so negative max is always rejected).
