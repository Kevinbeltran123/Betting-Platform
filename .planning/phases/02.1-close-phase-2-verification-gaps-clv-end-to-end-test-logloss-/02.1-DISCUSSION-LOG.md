## Parquet schema shape

### Q: How should home_goals/away_goals + opening_* + pinnacle_close_* columns land in Parquet?

| Option | Description | Selected |
|--------|-------------|----------|

**Notes:** User preferred concern-separation over read-time simplicity. Implication: pipeline.py:60-64 raise-on-missing-columns guard is replaced by a join-contract raise.

## CLV computation semantics

### Q: Which outcome per test row contributes to walk_forward_mean_clv_pct?

| Option | Description | Selected |
|--------|-------------|----------|
| Simulated EV pick: edge >= 5% (Recommended) | Mirrors Phase 3 pick engine; anchors CLV-03 +1% threshold. | ✓ |
| Model argmax (highest-probability outcome) | Simpler but doesn't track pick-engine behavior. | |
| All three outcomes averaged | Covers market efficiency signal but mixes non-bet outcomes. | |

**User's choice:** Simulated EV pick: edge >= 5%

### Q: What edge threshold does the simulated pick use for CLV inclusion?

| Option | Description | Selected |
|--------|-------------|----------|
| 5% fixed, matches PICK-01 (Recommended) | Hardcoded in backtest.py; single source of truth. | ✓ |
| Per-market YAML threshold | More flexible but introduces YAML dependency in training pipeline. | |
| 0% (include every argmax pick) | Defeats EV-filter simulation. | |

**User's choice:** 5% fixed, matches PICK-01

### Q: How do we handle folds with too few simulated picks to produce a stable CLV mean?

| Option | Description | Selected |
|--------|-------------|----------|
| Min 20 picks per fold, else clv_pct=None (Recommended) | Fold excluded from mean; null_clv_rows counts excluded rows. | ✓ |
| No minimum — always compute, even on 1 pick | Every fold counts; single-outlier risk. | |
| Min 50 picks per fold, else fail | Rigid; may block low-volume leagues. | |

**User's choice:** Min 20 picks per fold, else clv_pct=None
